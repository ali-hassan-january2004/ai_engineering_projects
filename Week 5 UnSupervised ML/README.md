# Intelligent E-Commerce Customer Segmentation System

An unsupervised machine learning pipeline designed to segment e-commerce customers using behavioral and transaction metrics, featuring automated feature engineering, K-Means clustering, and PCA visualization.

## Project Structure
- `data/`: Raw and processed customer transaction datasets.
- `notebooks/`: Step-by-step Jupyter notebooks for EDA, feature engineering, and modeling.
- `src/`: Modular Python scripts for reusable feature generation and clustering pipelines.
- `reports/`: Markdown documentation of cluster profiles and business recommendations.
